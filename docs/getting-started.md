# Начало работы

Требуется Go `1.27.0` или новее.

## Термины

- `Dependency`: конструктор (функция) + опциональные опции (name/group/as/key).
- `Dependencies`: список `Dependency`.
- `Container`: тонкая обертка над `dig.Container`, которая добавляет:
  - резолвинг "слотов" (`Provide` vs `Replace`)
  - модули (scopes) и приватность
  - валидацию без запуска конструкторов
  - экспорт графа зависимостей

## Создание контейнера

```go
cnt, err := godi.NewContainer(
  godi.WithConstructors(func() string { return "value" }),
)
```

`WithConstructors(items ...any)` принимает функции-конструкторы и готовые
значения `Dependency`, включая `Replace`, `Decorate` и их опции. Передавайте
значения, а не указатели `*Dependency`. Каждая функция оборачивается в `NewDependency`.
Повторные опции `WithConstructors` и `WithDependencies` добавляют регистрации.
Некорректный элемент приводит к ошибке `NewContainer` при обычной проверке
зависимостей. Создание опции, сборка контейнера и `Validate` не запускают конструкторы.

### Правила сигнатуры конструктора

Конструктор обязан быть функцией и возвращать:

- `func(...) T`
- `func(...) (T, error)`

Вариант "только `error`" запрещен.

## Получение значения

```go
got, err := cnt.Resolve[string]()
if err != nil {
  return err
}
```

`Resolve[T]()` — тонкая обёртка над `Invoke`: возвращает значение либо нулевое
значение `T` и исходную ошибку. Конструкторы остаются ленивыми, а их результаты
кешируются; повторное получение зависимости-указателя сохраняет её идентичность.
Автоматической привязки к интерфейсам нет: задайте её через `As[T]` или matchings.

Для named/group-параметров и сложной инъекции используйте `Invoke` с `dig.In`.
`Resolve` также принимает `dig.In` struct как `T`; отдельных опций name/group нет.

## Invoke

```go
var got string
err := cnt.Invoke(func(v string) {
  got = v
})
```

Первый вызов `Invoke`, `Resolve` или `Runnables` запускает контейнер, даже если
разрешение зависимостей завершилось ошибкой. После этого `Provide` запрещён.
Все вызовы контейнера выполняйте последовательно: `Container` не безопасен
для конкурентного использования.

## Добавление зависимостей после создания

```go
err := cnt.Provide(godi.CollectDependencies(
  godi.NewDependency(func() int { return 1 }),
))
```

`Provide` работает транзакционно: если новый набор зависимостей делает контейнер невалидным, состояние контейнера не "портится".

## Validate без запуска конструкторов

`Validate` выполняет dry-run сборку и проверяет, что все exposed слоты резолвятся.

```go
if err := cnt.Validate(); err != nil {
  // missing deps / invalid slots / invalid decorators, etc.
}
```
